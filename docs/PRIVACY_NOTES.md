# Privacy notes — AI menu reading and recipe suggestions

For the future privacy page, not shown anywhere in the app yet. No "partner" or vendor name belongs
on a screen — this is background for whoever writes that page's copy.

When you upload a menu photo or PDF to read it, that file is sent to a third-party AI service to be
read. It is processed for that one request and is not stored by us afterwards — the server deletes
it as soon as the request finishes (or fails), and never keeps a copy. When you ask for recipe
suggestions, only dish names (and, for matching, your own stock item names) are sent — never prices,
sales figures, or any other business data.
